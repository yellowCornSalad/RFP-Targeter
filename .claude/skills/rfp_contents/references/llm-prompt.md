# LLM 요약 프롬프트

`scripts/audit_contents.py` 의 `generate_summaries()` 가 Claude Haiku 4.5 호출에 사용하는 프롬프트.

## 모델

```
claude-haiku-4-5
```

- 가장 빠르고 저렴 (Sonnet 의 1/5 가격)
- 한국어 사업 요약에 충분한 품질
- 호출당 200 tokens 출력 (약 150자 한국어)

## System 프롬프트

```
당신은 한국 정부 R&D 공고를 카드에 표시할 짧은 요약을 만드는 전문가다.
본문과 첨부 텍스트를 종합해 150자 이내 한국어로 요약하라.

포함: 사업 본질·대상·예산·핵심 활동.
제외: 안내문구, 자격요건, 행정 절차, 인사말.

딱 한 문단으로 마침표까지 끝내라. 절대 150자 넘기지 마라.
```

설계 의도:
- "사업 본질" 우선 — 사용자가 카드 보고 1초 안에 무슨 사업인지 판단
- "안내문구·자격요건 제외" — boilerplate 매칭 (마이데이터·자금세탁) 의 거짓 요약 방지
- 150자 하드 컷 — 카드 UI 공간 제약

## User 메시지 템플릿

```python
prompt = f"제목: {title}\n발주: {agency or '미명시'}\n\n본문(첨부 포함):\n{body[:6000]}"
```

- 제목·발주 메타 먼저 → LLM 이 컨텍스트 빠르게 파악
- 본문 6000자 상한 — 토큰 비용 절감 + Haiku 컨텍스트 windowing
- 본문이 이미 첨부 통합된 상태 (`base.enrich_body_with_attachments`)

## 출력 후처리

```python
summary = resp.content[0].text.strip()
if len(summary) > 160:
    summary = summary[:157] + "..."
```

LLM 이 150자 약속 어기는 경우 가드. 160자 초과면 157자 + "..." 로 강제 컷.

## Rate Limit

- Haiku 4.5: 분당 50건 정도 처리 가능
- 코드: 호출 사이 `time.sleep(0.2)` — 분당 ~300 RPM 안전 마진
- 활성 보안 321건 처리: 약 1분 ~ 1분 30초

## 비용 추정

| 입력 토큰 | 출력 토큰 | 호출당 비용 (USD) |
|---------|---------|------------------|
| ~3000 (제목+발주+본문 6K자) | ~200 | $0.0003 |

321건 1회 처리 = 약 $0.1 (약 130원).
매시 cron 50건 제한 = 매시 약 20원 → 일 480원 → 월 14,000원.

## 품질 검증

생성된 요약 샘플:

```
이 사업은 KISA(한국인터넷진흥원)가 발주하는 마이데이터 중계 인프라
실증 지원사업으로, 데이터 중계 사업자 확대와 표준화된 안전한 데이터
전송 환경 구축을 목표로 한다. 예산은 약 1억원이며 클라우드 기반
인증·보안 인프라 실증을 핵심으로 한다.
```

- ✓ 사업 본질 명시 (마이데이터 중계 인프라)
- ✓ 발주 기관·예산 포함
- ✓ 핵심 활동 (인증·보안 인프라 실증)
- ✓ 150자 이내

## 프롬프트 변경 시

system 프롬프트 변경하면 기존 ai_summary 와 일관성 깨짐. 옵션:

1. **점진 적용**: NULL 만 새 프롬프트로 생성 (기존은 보존)
2. **전체 재생성**: `python scripts/audit_contents.py --force` — 비용 ~$0.1 추가

system 프롬프트는 한 번 정해지면 잘 안 바꿈. 큰 변경 시 사용자 컨펌 권장.
